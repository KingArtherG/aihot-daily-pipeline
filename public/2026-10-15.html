Visual Studio Copilot 与 SSMS 远程代码执行漏洞（CVE-2026-103572）技术分析 #7

MIT团队用机器学习修正误差，将两到六周天气预报准确率翻倍 #8

Claude Code 空闲压缩从摘要继续，可用 idleCompaction 关闭并自定义阈值 #9

Claude Code 的空闲压缩会让 Claude 从摘要而非完整上下文继续。作者说明可在 settings. 中设置 "idleCompaction": false 关闭，并通过 CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS 自定义阈值，默认为 200k。
